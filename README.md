# 🎧 Norm Player — Premium Offline & Cloud Music Player

  <img src="web/splash/img/dark-4x.png" alt="Norm Player Logo" width="180"/>
</p>

**Norm Player** — это современный, быстрый и стильный музыкальный плеер нового поколения, разработанный с акцентом на эстетику темной темы (**Neon Dark Mode**), эффекты матового стекла (**Glassmorphism**) и максимальное удобство воспроизведения аудио как офлайн, так и из облака.

---

## ✨ Ключевые возможности

* 🚀 **Офлайн-библиотека и бесшовный импорт**: Мгновенное добавление ваших любимых MP3-треков из памяти устройства и ПК в локальную коллекцию в один клик.
* 🌐 **Облачный поиск и скачивание новинок**: Встроенная вкладка поиска музыки в интернете с возможностью скачивания треков прямо в плеер для прослушивания без интернета.
* 🎨 **Уникальный авторский дизайн (Neon & Glassmorphism)**: Глубокая темная палитра `#0A0A12` с яркими неоновыми акцентами, плавной анимацией и современной типографикой.
* ⚡ **Высочайшая производительность и чистая архитектура**: Построен на актуальном стеке **Flutter**, **Riverpod (Clean Architecture)** и сверхбыстром хранилище **ObjectBox**.
* 📲 **Готовность к релизу в App Store & Google Play**: Поддерживает сборку `.ipa` и `.apk`/`.aab` архивов, включая автоматизированный CI/CD пайплайн в GitHub Actions для беспроводной установки через **Diawi**.

---

## 🛠 Технологический стек

* **Фреймворк:** [Flutter](https://flutter.dev/) / Dart
* **Архитектура & Стейт-менеджмент:** Clean Architecture + Riverpod
* **Локальная база данных:** ObjectBox (NoSQL)
* **Аудио-движки:** `just_audio`, `on_audio_query`, `audio_service`
* **CI/CD & Сборка:** GitHub Actions (Apple macOS Runners)
